# nick.py # 🎮 Генератор ников (Nickname Generator)

Привет! Это мой первый проект на Python — генератор никнеймов. 
Он создаёт случайные ники, склеивая твоё слово со стильными приставками и окончаниями.

## ✨ Что умеет

- Выбирать случайную приставку и окончание из списка
- Работать в цикле, пока ты не скажешь «нет»
- Принимать ответы «да», «Да», «ДА» (спасибо `.lower()`)

## 🛠️ Как запустить

1. Установи Python 3, если ещё не установлен.
2. Скачай файл `nick_generator.py`.
3. Открой терминал в папке с файлом.
4. Выполни команду:

```bash
python nick_generator.py
